# The-decarbonisation-pathway-of-the-alumina-industry-and-the-impact-from-Safeguard-Mechanism

Oral presentation slides for ENGY7112 Research Project (The University of Queensland):
**The Impact of the Safeguard Mechanism on Australia's Alumina Industry**.

## Viewing the slides

`ENGY7112_Oral_Presentation.html` is a single self-contained file (all images embedded).
Download it and open it in any modern browser.

- Next / previous slide: arrow keys, click, or swipe
- First / last slide: `Home` / `End`
- Fullscreen: `F`
